# Portfolio – Brightney Fernando

Persönliche Portfolioseite für das Modul EWEB (HS26) an der BFH.

## Aufbau

```
index.html        Seitenstruktur (semantisches HTML)
css/tokens.css    Farben, Schriften, Abstände (Design-Tokens, Hell/Dunkel)
css/base.css      Grundstyles, Typografie, Fokus, Buttons
css/layout.css    Header, Navigation, Bereiche, Footer
js/main.js        Einstiegspunkt (ES-Modul)
```

## Lokal ansehen

Die Seite nutzt ES-Module, deshalb über einen kleinen Server öffnen, z. B.:

```
python -m http.server
```

und dann http://localhost:8000 im Browser aufrufen.
